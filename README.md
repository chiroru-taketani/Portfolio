# Portfolio Web Site

CGメディア研究・インタラクティブシステム開発・映像・3DCG制作の作品を紹介するWebポートフォリオサイトです。
フレームワークに依存しないVanilla JavaScript、HTML5、CSS3を用いて構築されており、`data.js` をハブとしたデータドリブンな設計で作品情報の一元管理・動的描画を行っています。

---

## 🛠 ファイル・ディレクトリの詳細役割

### 1. ページ構成
| ファイル名 | 役割・説明 |
| :--- | :--- |
| **`index.html`** | ポートフォリオのトップ画面。`data.js` に登録された全作品をサムネイルカード形式で一覧表示します。 |
| **`about.html`** | 自己紹介・経歴・保有スキル・専門領域（C/C++、OpenGL、OpenCV、Blender、VFX等）を記載するページです。 |
| **`work.html`** | 作品の詳細ビュー画面。URLパラメータ（例: `work.html?id=project-1`）を解析し、該当作品の情報を動的に展開します。 |

### 2. スタイル & スクリプト
| ファイル名 | 役割・説明 |
| :--- | :--- |
| **`styles.css`** | サイト共通のデザイントークン、グリッド/フレックスボックスレイアウト、ダーク調のUIスタイル、レスポンシブ表示（PC/タブレット/スマートフォン）を定義。 |
| **`app.js`** | ページ初期化処理、URLパラメータからの作品ID取得、DOM生成、ギャラリーの表示切り替え、動画・モーダル制御などを担当。 |
| **`data.js`** | ポートフォリオ内の全作品データを管理するオブジェクト配列（`portfolioData`）と、各セクションの標準見出し（`sectionTitles`）を定義。 |

### 3. アセット管理 (`assets/`)
* **`assets/about/`**: プロフィール写真など、自己紹介ページ向けのアセットを配置。
* **`assets/works/{ID}/`**: 各作品番号（`01`〜`09`）ごとにディレクトリを分割し、キービジュアル（`key.*`）、ギャラリー画像（`gallery_*.*`）、システム構成図（`System_*.*`）、デモ動画（`*.mp4` / `*.mov`）、ソースコード（`*.cpp` 等）を整理して格納。

## 💡 データの管理設計 (`data.js`)

本サイトは、静的HTMLでありながら作品情報の追加・修正を容易にするため、`data.js` 内にスキーマを定義して管理しています。

### 作品データスキーマの例
```javascript
{
    id: "project-1",                            // 一意の識別子（URLパラメータと連動）
    title: "ユーザの手の動きに追従する動的な影の制御手法に関する研究",
    shortDescription: "影を操作するインタラクション",
    tags: ["研究", "インタラクション", "個人制作"],
    date: "2025.04",
    client: "卒業研究",
    thumbnail: "assets/works/01/01.png",
    content: {
        gallery: [ ... ],                      // ギャラリー用画像パス配列
        overview: {
            catchphrase: "...",                // キャッチコピー
            description: "...",                // 概要説明
            demoMedia: "https://youtu.be/KPO5YLKBtdE"
        },
        techStack: [                           // 使用言語・ハードウェア等のリスト
            { category: "使用言語・ライブラリ", details: "C/C++、OpenCV、OpenGL" },
            { category: "ハードウェア・センサー", details: "LiDAR、Kinect v2、大型LEDパネル" }
        ],
        achievements: [ ... ],                 // 受賞歴・学会発表実績
        background: [ ... ],                   // 開発背景と目的
        // 必要に応じて architecture, challenges, links, sourceCode などを柔軟に追加可能
    }
}
```

## 🚀 ローカルでの動作確認・プレビュー

静的ファイル構成のため、ローカルWebサーバーを起動することで動作確認が可能です。

### 方法1: Python 簡易HTTPサーバー（推奨）
ターミナルで本ディレクトリに移動し、以下のコマンドを実行します:
```bash
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` にアクセスします。

### 方法2: VSCode Live Server拡張機能
1. VSCodeで `Portfolio` フォルダを開きます。
2. 画面右下の **「Go Live」** ボタンをクリック、または `index.html` を右クリックして **「Open with Live Server」** を選択します。

## 📝 新しい作品を追加する手順

1. **アセットの準備**:
   * `assets/works/` 配下に新しい番号フォルダ（例: `assets/works/10/`）を作成します。
   * サムネイル、ギャラリー画像、デモ動画、構成図などを配置します。
2. **`data.js` への追記**:
   * `portfolioData` 配列の末尾に、新しい作品オブジェクトを追加します。
   * `id` はユニークな値（例: `project-10`）を設定します。
3. **ローカル確認**:
   * トップページ（`index.html`）にカードが追加されていることを確認します。
   * カードをクリックし、`work.html?id=project-10` で各セクションが正しくレンダリングされるか確認します。
